Privacy Policy

Pheonix Payroll Document Automation TEST
Last updated: 14 October 2026

This policy describes the TEST payroll document automation operated for Pheonix General Construction Limited's Reforestation operations. The application is intended for authorized internal use, not for public payroll processing.

Information accessed

The application may access Google Drive folders and files that an authorized Google account selects or grants to it. The separate payroll automation workflow reads data from a designated TEST Google Sheets workbook, including employee names, attendance, pay amounts, statutory deductions and banking details, to prepare payroll documents.

How information is used

Information is used to verify access to the designated TEST folder, validate payroll calculations, generate payroll documents, and upload those documents to the authorized TEST folder. The browser-based folder selection page does not itself generate or upload payroll documents.

Storage and security

Generated payroll documents may be stored in a private GitHub Actions artifact and in the access-controlled Google Drive TEST folder. OAuth credentials used by the automated workflow are stored as encrypted GitHub Actions repository secrets, not in this public website's source code. Access is limited through Google account permissions and the OAuth drive.file scope. No security measure guarantees absolute protection.

Sharing

The application is not intended to sell employee information or share payroll data with advertisers. Data is processed using Google and GitHub services to perform the described workflow and may be accessible to authorized administrators and service providers according to their permissions and applicable terms.

Retention and deletion

GitHub Actions TEST document artifacts are currently configured for seven-day retention. Files uploaded to Google Drive remain there until removed by an authorized account holder. Account holders may revoke the application's Google access through their Google Account permissions. Revoking access does not automatically delete previously generated files or copies.

Google API data

Information received from Google APIs is used only for the functionality described here, subject to the Google API Services User Data Policy, including applicable Limited Use requirements.
